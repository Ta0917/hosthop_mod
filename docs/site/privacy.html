プライバシーポリシー

HostHop（開発者: Ta0917）／最終更新: 2026年11月11日

HostHop は、Minecraft の共有ワールド MOD です。このポリシーは、HostHop が、どの情報を扱い、どう使うかを説明します。

1. 扱う情報

情報使い道保存場所
Google アカウントの認可情報（アクセストークン、更新トークン）利用者自身の Google Drive に、ワールドのデータを保存・取得する利用者のPCだけ。暗号化して保存します（Windows の資格情報保護を使用）。開発者には送られません。
Google Drive のファイル（ワールドのスナップショット、バックアップ）共有ワールドの保存と、ホスト交代時の復元利用者が指定した、利用者自身の Google Drive のフォルダー
ワールドID、参加者ID、招待コードのトークン（ハッシュ化したもの）参加者の確認、誰がホストかの管理（リース）開発者が運用する Cloudflare（Workers と D1）
保存世代、Drive のファイルID・サイズ・ハッシュ値、ホストの接続先アドレス最新データの特定、ホストへの接続案内同上（Cloudflare）
MOD の識別子・バージョン・ファイルのハッシュ値、設定ファイルのハッシュ値参加者どうしの MOD 構成の食い違いの検出同上（Cloudflare）

ワールドの内容そのものは、利用者の Google Drive にだけ保存され、開発者のサーバーには保存されません。

2. Google ユーザーデータの扱い

  • HostHop が要求する Google の権限は、https://www.googleapis.com/auth/drive.file だけです。HostHop が作成した、または、利用者が選択したファイルにだけ、アクセスします。
  • Drive 上のそのほかのファイル、連絡先、メール、個人情報は、読み取りません。
  • アップロードしたファイルの確認のために、アクセストークンが、開発者の Cloudflare Worker に一時的に送られます。Worker は、そのトークンを使って、Google Drive API でファイルの名前・サイズ・ハッシュ値だけを確認し、トークンは、保存しない設計です。
  • Google ユーザーデータは、HostHop の機能の提供だけに使い、広告、販売、第三者への提供、人手による閲覧、機械学習の学習には、使いません。
  • HostHop による、Google API から受け取った情報の使用と、他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に、準拠します。

3. 第三者サービス

  • Google Drive: ワールドの保存先です。
  • Cloudflare: 管理用サーバー（Workers と D1）の運用に使います。Cloudflare が、運用上のログを、自社の方針で、記録することがあります。
  • e4mc: ホストのワールドに、外部から接続するための、リレーです。Minecraft の通信が、e4mc のリレーを経由します。e4mc は、HostHop とは別の、第三者の MOD です。

4. 保存期間と削除

  • 利用者のPCの認可情報は、config\hosthop\credentials.dat を削除すれば、消えます。
  • Google の権限は、Google アカウントの権限の管理ページで、いつでも、取り消せます。
  • Drive のワールドデータは、利用者が、自分の Drive から、削除できます。
  • Cloudflare 上の記録の削除を希望する場合は、下記の連絡先へ、ご連絡ください。

5. 利用対象

HostHop は、招待された、少人数の参加者だけが使う、実験的なソフトウェアです。不特定多数への提供や、13歳未満の方の利用は、想定していません。

6. 変更

このポリシーは、必要に応じて、改訂します。重要な変更は、このページに、掲載します。

7. 連絡先

GitHub Issues からご連絡ください。

ホームプライバシーポリシー利用規約

English summary: HostHop requests only the Google Drive drive.file scope. OAuth tokens stay encrypted on the user's PC. A Cloudflare Worker stores only world/lease records, Drive file IDs and hashes, and mod/config hashes; it does not store Google tokens. Google user data is used solely to provide the app's features and is never sold, shared, or used for advertising or AI training. HostHop's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
