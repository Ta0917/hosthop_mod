2026年11月9日時点の公式公開情報と、現在の実装に基づく目安です。各アカウントの利用量や契約を確認した結果ではなく、無料で運用できる保証ではありません。

- Cloudflare Workers Freeは1日10万リクエストです。ホスト中は15秒ごとにリースを更新するため、24時間連続なら更新だけで約5,760リクエストになります。参加者の状態確認、保存、他のWorkerからの利用も別に加算されます。[Workers limits](https://developers.cloudflare.com/workers/platform/limits/)
- D1 Freeには読み取り行数・書き込み行数・ストレージの制限があります。行数はリクエスト数と同じではなく、ほかのデータベースの使用分も影響します。上限に達した場合の動作は公式の最新情報を確認してください。[D1 pricing](https://developers.cloudflare.com/d1/platform/pricing/)
- Google OAuth同意画面が外部向けのテスト状態の場合、利用するDrive権限では更新トークンが7日で失効する場合があります。失効時はHostHop画面でGoogle Driveを再連携します。[Google OAuth token expiration](https://developers.google.com/identity/protocols/oauth2#expiration)
- 数GBの実データ、3〜5人の長時間プレイ、無料枠内の実際の消費量は未検証です。合成データでの確認やリクエスト数の計算から実運用の安定性は保証できません。
- 隔離された実Cloudflareのワールドで、同じテスト用招待情報を使う5並列の状態照会を5回実行し、すべて応答を受け取りました。これは5人の同時プレイや、5つの異なる参加者アカウントを検証したものではありません。
- オフラインで約2.16GBのZIPを2世代作成し、差分から完全に一致するZIPへ復元できました。このPCで生成から照合まで約338秒でした。内容には同じ疑似乱数の塊を繰り返しており、実ワールドやネットワーク転送の性能を表す数値ではありません。

## ホスト中の定期バックアップ

通常のタイマーは5分間隔です。チャンクの保存準備が整うまで最大30秒再試行し、前回の処理が続いている回はスキップをログに記録します。Minecraft 26.2のサーバースレッドで保存を開始し、チャンク・エンティティ・POI・SavedDataの書き込みを各IOキューで区切ります。SavedDataは書き込みが完了してから、次の書き込みの前に読み取ります。リージョンは区切りより後の書き込みで上書きされるページを退避します。リージョンの読み出し、ZIP作成、差分の復元照合、アップロードはワーカーで行います。定期保存の直後に通常のオートセーブが重ならないよう、次回のオートセーブを予約し直します。Windowsの通常権限で動作します。

サーバースレッドにはMinecraftのシリアライズ、一部の読み込み待ち、小ファイルの取得が残ります。小ファイルには合計16 MiB、リージョンの退避には64 MiBの上限があり、上限や保存エラーに達した回は公開を中止します。整合性の対象はMinecraftの保存経路と、サーバースレッド上で保存を完了するMODです。独自の非同期ファイル書き込みを行うMODや、外部プロセスによる同時編集には別途連携が必要です。

検証は `-PhosthopClientDir` に指定した隔離クライアントとローカルの模擬ストレージで実行します。隔離クライアントには `.hosthop-test-client` と停止済みの `saves/seed` を用意し、ワールドに必要なMODを入れます。`runClient -PhosthopHostSmoke -PhosthopCheckpointSmoke -PhosthopCheckpointTimerSmoke=production` では5分タイマーで最初のバックアップを作り、次のホストで作成した差分を別のワールドとして開きます。テストは復元後のブロック、エンティティ、プレイヤー所持品と、バックアップ処理中の最大ティック間隔を記録します。

約626 MBの `dqm` のコピーとDQMVI 0.34.20で、5分タイマーによるフル保存と手動の差分保存に成功しました。差分から起動した別ワールドで、検証用のブロック、エンティティ、所持品を確認しました。SavedDataの待機を移した後のフル保存時のサーバースレッド処理は321 ms（前の版は898 ms）、バックグラウンドコピーは6.1秒でした。バックアップ処理中の最大ティック間隔は332 ms（前の版は912 ms）でした。測定には1人のローカルプレイヤーと模擬ストレージを使用しました。
