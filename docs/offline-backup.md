# 停止済みワールドのコピーのバックアップ

これは独立したローカル実験ツールで、共有ワールドMODの同期機能ではありません。Minecraftを終了し、書き込みが完全に止まったワールドの**コピー**に対して使ってください。ツールはゲームを停止せず、稼働中のワールドの整合性も保証しません。元データを操作せず、復元先には存在しない新しいフォルダーを指定してください。

Python 3.12以降でリポジトリのルートから実行します。

```powershell
python poc/offline_backup.py create '停止済みワールドのコピー' '新規バックアップ.zip'
python poc/offline_backup.py verify '新規バックアップ.zip'
python poc/offline_backup.py restore '新規バックアップ.zip' '新規復元フォルダー'
```

作成時はファイルごとのサイズ・SHA-256を保存し、ZIPの作成後に内容を再検証します。復元前にもアーカイブ全体を検証し、復元時にも内容を検証します。既存バックアップと既存復元先の上書きは拒否します。途中失敗した場合は不完全なファイルや復元先が残ることがあります。成功表示がない結果は使用しないでください。暗号化や改ざん者に対する認証、クラウド転送、停電からの完全な保護はありません。
